# 🚀 TaskFlow - Gestion de projet collaboratif

**TaskFlow** est une PWA (Progressive Web App) conçue pour simplifier la gestion des processus en équipe et fluidifier la communication entre les membres, afin de faciliter l'avancement des projets. 

Notre philosophie : **"Passer de l'idée à la livraison, ensemble et sans friction."**

---

## ✨ Fonctionnalités principales

- **Projets & Jalons** : Structurez vos projets et définissez des étapes clés.
- **Tâches intelligentes** : Priorités, statuts (Kanban), sous-tâches et dépendances.
- **Collaboration avancée** : Fils de discussion par tâche, mentions (`@`), pièces jointes.
- **Tableaux de bord** : Visualisez l'avancement et les blocages en temps réel.
- **Notifications** : Alertes en app et par email (via Resend).
- **Paiements intégrés** : Gestion des abonnements via Stripe.

---

## 🛠️ Stack Technique

| Catégorie | Technologie |
| :--- | :--- |
| **Frontend** | Next.js 15 (App Router), React 19, TypeScript |
| **Styling** | Tailwind CSS |
| **Backend / BaaS** | Supabase (PostgreSQL, Auth, Storage, RLS) |
| **Paiements** | Stripe |
| **Emails** | Resend |
| **Hébergement** | Vercel (Frontend) / Supabase (DB) |
